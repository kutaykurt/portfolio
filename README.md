# Portfolio - Kutay Kurt

Ein modernes, professionelles Portfolio, das mit **React**, **Vite** und **Framer Motion** entwickelt wurde. Das Design besticht durch eine elegante **Glassmorphism**-Ästhetik, flüssige Animationen und eine intuitive Benutzerführung.

## 🚀 Technologien

- **Frontend**: React 18
- **Build Tool**: Vite
- **Styling**: Vanilla CSS (Modern Design System)
- **Animationen**: Framer Motion
- **Icons**: React Icons
- **Routing**: React Router 6
- **Email**: EmailJS Integration (im Kontaktformular)

## ✨ Features

- **Responsive Design**: Optimiert für alle Endgeräte (Mobile, Tablet, Desktop).
- **Glassmorphism UI**: Hochwertige visuelle Effekte mit Backdrop-Filter.
- **Interaktive Projekte**: Showcase-Bereich mit dynamischen Karten.
- **Kontaktformular**: Direkter Email-Versand ohne Backend-Setup.
- **Scroll-Animationen**: Sanfte Einblendeffekte für ein premium Gefühl.

## 🛠️ Installation & Setup

1. **Klone das Repository**:
   ```bash
   git clone https://github.com/dein-username/portfolio.git
   ```

2. **Installiere Abhängigkeiten**:
   ```bash
   npm install
   ```

3. **Konfiguriere Environment Variables**:
   Erstelle eine `.env` Datei im Hauptverzeichnis (siehe `.env.example`) und füge deine EmailJS Keys hinzu.

4. **Starte den Development Server**:
   ```bash
   npm start
   ```
